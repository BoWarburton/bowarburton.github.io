Supported AP pseudocode and tracing tips

This is a robot-focused subset of AP pseudocode, not a full AP language interpreter. Keywords ignore capitalization. Use braces around every loop or conditional body.

MOVE_FORWARD()
ROTATE_LEFT()
ROTATE_RIGHT()
REPEAT 3 TIMES { ... }
REPEAT UNTIL(NOT CAN_MOVE(forward)) { ... }
IF(CAN_MOVE(right)) { ... } ELSE { ... }
steps ← 3
REPEAT steps TIMES { ... }
DISPLAY(steps)

CAN_MOVE(left/right/forward/backward) checks one square relative to the robot's facing direction. It neither moves nor turns the robot. NOT, AND, OR, Boolean values, numeric variables, comparisons, and arithmetic are supported. Assign with ← or <-. Compare with =. Use MOD for remainders. You can add // comments.

Lists, procedures, INPUT, and arbitrary JavaScript are not supported. A repeat count must be a nonnegative whole number. REPEAT UNTIL checks the condition before each repetition and stops when it becomes true. Each Step executes a command, assignment, output, or condition check. Loop setup and the final exit check also appear in the trace.

Turns change orientation in place. An attempted move into a wall or beyond the grid leaves the robot in its square and terminates the program. A green goal is a practice marker. Reaching it does not automatically stop the program. Execution stops after 10,000 steps to catch accidental infinite loops.

Keyboard: F6 steps, F7 runs or pauses, Escape pauses. Reset clears the execution trace while keeping your code and grid.
